# Estrategia de hashtags — tamaño, no volumen

> Consultado por `docs/flujo-guiado.md` → "Copy de publicación", paso de
> hashtags. Reemplaza el viejo criterio de "hashtags relevantes al tema" por
> un modelo con tamaño explícito.

El bloque de 20-30 hashtags está muerto. 3 a 5 hashtags bien elegidos y bien
dimensionados superan a 30 al azar — en 2026 los hashtags funcionan más como
etiqueta de tema para que Instagram categorice el post, no como motor de
descubrimiento. El alcance real viene de sends y saves, no de la pestaña de
hashtags.

## El modelo: tamaño, no cantidad

El **tamaño** de un hashtag es su volumen total de posts. La estrategia es
una mezcla para que el post pueda posicionar en los tags chicos mientras
toca los grandes de pasada.

| Nivel | Volumen | Rol | Cuántos usar |
|---|---|---|---|
| **Nicho** | menos de 50k posts | donde una cuenta chica/mediana realmente puede posicionar y quedarse visible horas | 2-3 |
| **Medio** | 50k-500k | punto dulce: audiencia suficiente, competencia superable | 1-2 |
| **Amplio** | 500k+ | un toque breve de categoría — posicionas minutos, no horas | 0-1 |

**Default: 3-5 en total.** Agregar más allá de 5 no suma alcance y puede
leerse como spam.

## Por qué gana el nicho

- Un tag de nicho (menos de 50k) tiene rotación lenta, así que el post se
  mantiene arriba en "Recientes" y "Top" por horas, no segundos.
- Posicionar en un tag de nicho es alcanzable para una cuenta chica;
  posicionar en uno de 5M no lo es — el tag amplio es sobre todo una señal de
  categorización.
- Los tags de nicho también traen una audiencia más relevante, lo que
  significa mejores saves y sends — que es lo que de verdad mueve el alcance.

## Cómo armar el set (la receta 3-5)

1. **2-3 tags de nicho** que describan exactamente a quién le habla el post.
   Son los que hacen el trabajo pesado — ganan visibilidad sostenida y
   posicionada.
2. **1-2 tags medios** que nombren el subtema. Extienden el alcance a una
   audiencia cálida y relevante.
3. **0-1 tag amplio**, solo si uno calza de verdad como etiqueta de
   categoría. Sáltalo si nada calza — un tag amplio irrelevante diluye el set.
4. **Que calce con el contenido.** Cada tag debe describir el contenido real.
   Un tag popular pero fuera de tema entrena mal al algoritmo de
   recomendación y baja el alcance futuro.
5. **Evita tags de granja de engagement o marcados como spam**
   (`#sigueme`, `#likeporlike`, `#f4f` y variantes). Ante la duda, sáltalos.

## Señales para estimar el tamaño

No hay forma de ver el volumen exacto desde la API — estima por
especificidad, o pídele al usuario que verifique el conteo en la app:

- **Señal de nicho:** específico, combina dos palabras o nombra una
  comunidad exacta (`#limpiezaintimachile`, `#saludsinfiltros`,
  `#medicinabasadaenevidencia`). Si sientes que solo alguien en tu mundo
  exacto lo escribiría, es nicho.
- **Señal media:** un subtema reconocible (`#saludpreventiva`,
  `#tipsdesalud`, `#contenidomedico`). Conocido pero no universal.
- **Señal amplia:** una palabra común que todo el mundo usa
  (`#salud`, `#bienestar`, `#medicina`, `#fitness`). Trátalos como etiqueta,
  usa como máximo uno.

## Ubicación

- **Al final del caption** o en el **primer comentario** — el alcance es el
  mismo. El primer comentario deja el caption más limpio. Nunca a mitad de
  una oración.
- **No repitas el mismo set de 5 en cada publicación.** Instagram puede leer
  un set idéntico repetido como comportamiento automatizado. Rota el set
  según el tema de cada carrusel.

## Hashtags de marca

Un hashtag propio (ej. `#recetariodrX`, si la cuenta lo usa de forma
consistente) no genera descubrimiento por sí solo, pero construye un
archivo buscable. Cuenta como uno de los slots de nicho si es genuinamente
chico.

## Qué no hacer

- 20-30 hashtags amontonados al inicio del caption. Es la señal de spam de
  2026.
- Copiar y pegar un "pack viral de hashtags" de tags amplios genéricos —
  compite contra millones de posts, imposible de ganar.
- Usar tags que no calzan con el contenido para perseguir más alcance —
  entrena mal al algoritmo y termina bajando el alcance.
- Esconder 30 tags detrás de puntos o saltos de línea para "verse limpio".
  Sigue siendo spam, sin beneficio de alcance.

## Plantilla rápida

```
[texto del caption]
.
#tagNicho1 #tagNicho2 #tagNicho3 #tagMedio1 #tagAmplioOSalta
```

3 nicho, 1 medio, 1 amplio (o descarta el amplio y corre con 4). Rota los
tags de nicho según el tema de cada carrusel.
